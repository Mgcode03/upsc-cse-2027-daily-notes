# UPSC CSE 2027 — Daily Study Notes

**Repo:** https://github.com/Mgcode03/upsc-cse-2027-daily-notes  
**Owner:** Mgcode03  
**Target:** Civil Services Examination 2027 (Prelims 23 May 2027, Mains from 20 August 2027)

## How to use this repo

1. Every evening a new file appears under `daily/`.
2. Open **only** that day’s file.
3. Read it end to end. The text is written to be studied, not skimmed.
4. Do not hunt for books or PDFs. The file itself is the lesson.

File format:

```
daily/YYYY-MM-DD.md
```

Example: `daily/2026-08-27.md`

Tracker: `PROGRESS.md`. Curriculum seed: `CURRICULUM.md`.

### Prelims
- Paper I GS: 100 questions, 200 marks, 2 hours. Decides cutoff.
- Paper II CSAT: 80 questions, 200 marks, 2 hours. Qualifying at 33% (66.67 marks).
- Negative marking: one-third.

Recent General Prelims GS-I cutoffs /200: 2023 = 75.41 · 2024 = 87.98 · 2025 = 92.66

### Mains + Interview
Qualifying: Indian Language 300, English 300.
Merit 1750: Essay 250, GS I–IV 250 each, Optional I & II 250 each.
Interview 275. Final 2025.

Recent General Mains /1750: 2023 = 741 · 2024 = 729 · 2025 = 739
Recent General final /2025: 2023 = 953 · 2024 = 947 · 2025 = 963
